# TapQuest 

TapQuest is a mini game collection developed using Java that includes two classic games: Whack-a-Mole and Tic Tac Toe. The project focuses on creating simple, interactive, and fun gameplay while applying programming concepts and game logic.

## Games Included

###  Whack-a-Mole
A reaction-based game where players click randomly appearing moles to score points before time runs out.

Features:
- Random mole generation
- Score system
- Timer
- Increasing challenge

---

### Tic Tac Toe
A classic two-player strategy game where players take turns placing X and O to create a winning pattern.

Features:
- Two-player gameplay
- Win and draw detection
- Simple UI
- Restart option

---

## Technologies Used
- Java
- Java Swing / JavaFX
- Object-Oriented Programming

## Objective
To build simple games while improving programming, problem-solving, and game development skills.
